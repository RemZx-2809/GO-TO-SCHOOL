# 🎓 GoToSchool - เว็บแอปบันทึกค่าโดยสารไปมหาวิทยาลัยรายวัน

เว็บแอปพลิเคชันสำหรับบันทึกค่าเดินทางไปมหาวิทยาลัยรายวัน พร้อมสรุปยอดค่าใช้จ่ายเป็นรายเดือนตามปฏิทินจริง ออกแบบมาสำหรับใช้งานบนโทรศัพท์มือถือและคอมพิวเตอร์อย่างสะดวก รวดเร็ว และสวยงาม

🔗 **Repository:** [https://github.com/RemZx-2809/GO-TO-SCHOOL](https://github.com/RemZx-2809/GO-TO-SCHOOL)

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. 📅 **ระบบเลือกวันที่แบบล็อกเดือน/ปี (Sticky Date Selector)**
   - แยกช่องเลือก วัน / เดือน / ปี พ.ศ.
   - **เดือนและปีที่เลือกไว้จะถูกจำ (Sticky) ค้างไว้ตลอด** บันทึกวันถัดไปแค่เลื่อนเปลี่ยน "วัน" อย่างเดียว
   - **แถบสไลด์วันที่แนวนอน (Swipable Day Strip)** เลือกวันได้ด้วย 1-Tap ไม่เด้งบังหน้าจอ
   - มีปุ่มลัด **"วันนี้"** และปุ่ม **"ตารางวัน 📅"** สำหรับดูปฏิทินทั้งเดือนแบบ Grid

2. 🚌 **การบันทึกรายการที่รวดเร็ว (Fast 1-Click Logging)**
   - แยกชัดเจนระหว่าง **ขาไป มหา'ลัย 🎓** และ **ขากลับ บ้าน/หอ 🏠**
   - ปุ่มลัดประเภทการเดินทาง: รถเมล์, รถไฟฟ้า (BTS/MRT/ARL), วินมอเตอร์ไซค์, รถตู้/มินิบัส, สองแถว, แท็กซี่, เรือ และปุ่มระบุเอง
   - ปุ่มลัดราคาด่วน: 8, 10, 15, 20, 25, 30, 35, 40, 50, 60 บาท หรือพิมพ์จำนวนเงินเอง
   - แท็กหมายเหตุด่วน: ต่อ 1, ต่อ 2, ต่อ 3, กลับเข้าหอ ฯลฯ
   - รองรับการบันทึกหลายรายการ/หลายต่อในวันเดียวกัน

3. 📊 **การสรุปผลและรายงานรายเดือน (Monthly Summary & Analytics)**
   - สรุปยอดรวมค่าใช้จ่ายตามเดือนปฏิทินจริง (เช่น กันยายน 2569, ตุลาคม 2569)
   - ดูสถิติย้อนหลังได้ทุกเดือน/ปี
   - แสดงยอดรวมทั้งเดือน, ยอดแยกขาไป vs ขากลับ, สัดส่วนเปอร์เซ็นต์ (Ratio Bar)
   - แยกค่าใช้จ่ายตามประเภทการเดินทาง พร้อมแถบเปอร์เซ็นต์
   - แสดงจำนวนวันที่เดินทางจริง และค่าเฉลี่ยต่อวัน / ต่อเที่ยว

4. 📋 **ประวัติรายการรายวัน & จัดการข้อมูล (Daily Log & History)**
   - จัดกลุ่มรายการตามวัน 1..31 พร้อมยอดรวมแต่ละวัน
   - มีปุ่ม **แก้ไข (Edit)** และ **ลบ (Delete)** รายการย้อนหลังได้
   - ค้นหารายการตามชื่อหรือหมายเหตุ และกรองเฉพาะขาไป/ขากลับได้

5. 💾 **การเก็บข้อมูลและการส่งออก (Data Persistence & Backup)**
   - บันทึกข้อมูลลงใน **LocalStorage** ในเครื่อง ไม่ต้องต่อเน็ต ข้อมูลไม่หายเมื่อปิดเว็บ
   - **ส่งออกไฟล์ Excel / CSV** สำหรับทำบัญชี
   - **สำรองข้อมูล (Export JSON)** และ **กู้คืนข้อมูล (Import JSON)**

6. 🌓 **ธีมมืดและธีมสว่าง (Dark / Light Mode)**
   - สลับธีม Dark / Light ได้ตามต้องการ สบายตาในทุกสภาพแสง

## 💻 วิธีเปิดใช้งาน (Getting Started)

เพียงดาวน์โหลดหรือ Clone โปรเจกต์ แล้วเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้:

```bash
git clone https://github.com/RemZx-2809/GO-TO-SCHOOL.git
cd GO-TO-SCHOOL
```
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ เช่น Google Chrome, Safari, Microsoft Edge ได้ทันที ไม่ต้องติดตั้งโปรแกรมหรือรันเซิร์ฟเวอร์เพิ่มเติม
